## Novità della 3.2

### ZimbraViewer anche per macOS e Linux, completamente standalone
Python, Qt e Chromium sono inclusi nei pacchetti: non serve installare nient'altro.

| Sistema | File |
|---|---|
| Windows 10/11 (x64) | `ZimbraViewer-3.2-windows-x64.exe` |
| macOS 12+ Apple Silicon (M1…M4) | `ZimbraViewer-3.2-macOS-arm64.dmg` |
| macOS 12+ Intel | `ZimbraViewer-3.2-macOS-x86_64.dmg` |
| Linux x86_64 (Debian 12+, Ubuntu 22.04+, Fedora 36+, Arch, openSUSE…) | `ZimbraViewer-3.2-x86_64.AppImage` oppure `ZimbraViewer-3.2-linux-x86_64.tar.gz` (con `installa-linux.sh`, voce nel menu) |

- **macOS**: apertura dal Finder (*Apri con*, trascinamento sull'icona nel Dock), «Mostra nella cartella» con il Finder, certificati del portachiavi di sistema, HTTPS verificato.
- **Linux**: AppImage e `.tar.gz` installabile per il solo utente, «Mostra nella cartella» con il file manager, CA della distribuzione; la sandbox di Chromium si disattiva solo dove la distribuzione la impedisce (es. Ubuntu 23.10+ con AppArmor).
- Cache e impostazioni nelle cartelle standard di ogni sistema; stile coerente su tutte le piattaforme.
- Selezionando una cartella si vedono anche le mail di tutte le sue sottocartelle.

Su macOS l'app non è firmata da Apple: al primo avvio *Impostazioni di Sistema → Privacy e sicurezza → Apri comunque*. Istruzioni complete nel [README](https://github.com/KonjikiNoYami1991/ZimbraViewer#download-e-installazione).

> Sono disponibili versioni più recenti: la [3.2.1](https://github.com/KonjikiNoYami1991/ZimbraViewer/releases/tag/v3.2.1) (calendario, contatti e altri dati, accessibilità) e la [3.2.2](https://github.com/KonjikiNoYami1991/ZimbraViewer/releases/tag/v3.2.2) (motore delle firme aggiornato). Su Linux e macOS si consiglia di aggiornare: dalla 3.2.1 i pacchetti includono anche il database dei fusi orari.

### What's new in 3.2 (English)

ZimbraViewer is now available as standalone builds for **macOS** (Apple Silicon and Intel, `.dmg`) and **Linux** (`.AppImage`, `.tar.gz`), alongside Windows — Python, Qt and Chromium bundled. Finder integration on macOS, file-manager integration on Linux, system certificate stores, standard per-OS data folders.
